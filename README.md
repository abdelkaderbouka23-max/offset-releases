# OFFSET for Windows

Downloads and updates for OFFSET, the app that replaces the NVIDIA Control Panel:
profiles that switch with your games, real FPS, an in-game overlay, instant replay and recording.

**[Download the latest version](https://github.com/abdelkaderbouka23-max/offset-releases/releases/latest/download/OffsetApp-win-Setup.exe)** (Windows 10 and 11).

Installed copies update themselves from the releases of this repository.
